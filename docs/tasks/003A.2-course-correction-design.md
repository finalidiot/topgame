# 003A.2 course correction: implementation design

The human supersedes the mutation-heavy scope recorded in the earlier 003A.2
report. Preserve its evidence and accepted foundation; retire Wallbreaker,
Ricochet Engine, Centrifuge, Perpetual Orbit, Flywheel Release, Countersteer,
Reactive Plating and Sacrificial Damper. Their four parents end at II. The seven
accepted mutation pairs and the seven-family cap remain.

This table precedes runtime implementation. Values are modest first-pass
candidates, subject to measured combinations and source-ledger validation.

| Family / role | Rank I -> II | Visual identity / activation | Constraints, combinations and RPM |
| --- | --- | --- | --- |
| Crimson Impact / offence | Outgoing impact ×1.08 -> ×1.14 | Red rim chevrons, always while owned | Multiplicative outgoing solver scalar; Wake/Chain/Comet; no recovery |
| Azure Stability / footing | Incoming wobble ×.90 -> ×.82; solver inverse-mass coefficient ×.94 -> ×.89 | Blue segmented corona, always while owned | No damage immunity; Centre/Gyro/Anchor; no RPM gain |
| Emerald Endurance / efficiency | Continuous running drain ×.94 -> ×.90 | Green paired rotating arcs, always while owned | Passive/movement/Brake/wobble running costs only; existing passive floor retained; no collision, Burst or power-cost discount; Orbit/Clutch/Gear; no regeneration |
| True Bearing / wobble control | Existing wobble recovery ×1.16 -> ×1.28 | Lavender inner crown ticks, always while owned | Existing low-spin wobble floor retained; Gyro/Sink/Crash Guard; no RPM restored |

| Prismatic Current / adaptation | Every 8s: impact ×1.06/1.10, speed ×1.05/1.08, incoming wobble ×.91/.85, or drain ×.95/.92 | Four inner diamonds; red/cyan/blue/green state plus explicit state label | Dedicated Run-seeded per-owner stream, one initial draw then one draw among other three at each change; no repeats, no control inversion; no regeneration |

All six have I and II only. Each fresh movement/solver query applies its rank
once, after accepted existing power effects and before the existing physical
coefficients/resource floors. Combined new outgoing scalar caps at 1.30; new
wobble factor floors at .50; new displacement factor floors at .80; new running
drain floors at .80; recovery multiplier caps at 1.40; speed caps at 1.10. These
are bounds on new content, not changes to accepted existing modifiers. No part
ratings, saved assembly, family cap, Director count or AI tuning changes.

RunContext has no resumable persistent power serializer. Collection saves
parts, currency and receipt/reward transactions, not live Run powers. Incoming
encounter ownership descriptors carrying a retired branch deterministically
normalize to its existing parent Rank II and clear only that branch. Historical
JSON/art assets remain immutable; retired descriptive metadata is readable as
archived/inactive, outside live offers and renderer registrations. No random
substitution, Run wipe or saved-data migration is used.

Aura shapes hug projected tops with separated radii and thin translucent rims.
Rank styling and universal focused-card frames have separate semantics.
Procedural vector geometry is appropriate for these runtime rim accents and
small matching identity cards; no detached mechanical sprite or full-screen
bloom is introduced.

The implementation uses native vector SVG card/icon atlases with six bounded
poses per row and matching runtime rim shapes. Source assets are editable text.

Azure changes the solver inverse-mass coefficient, not a fixed percentage of
received shove. With equal effective masses its full-top recoil share falls
about 3.09% / 5.82%; opposing recoil increases. Other masses/braces change that
result. The public copy promises firmer footing without a universal shove
percentage. No extra damage multiplier is added.
