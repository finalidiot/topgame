# Original melodic metal music — Task 002C.6

Foundry Circuit / Steel Horizon is an original32-bar,172 BPM composition in
E minor. Written palm-muted gallops, power-chord changes, a recurring melodic
hook, harmonized thirds, bass, double-kick strokes and drum fills provide the
requested fast melodic metal energy. Four eight-bar sections move through a
verse, rising hook, contrasting bridge and anthem return. Every pitch, rhythm
and instrument is authored for this game; no song, melody or audio sample was
borrowed.

The title plays the complete introduction. The workshop keeps the same harmony
with clean strings, lower hook fragments and restrained percussion. The Run
starts with wide rhythm guitars, bass and backbeat; the pressure layer adds the
lead and complementary double-kick strokes; the boss layer adds harmonized
leads, sustained power chords, a lower counterline and tom/crash cadences.

## Editable source and native audio

`assets/audio/music/foundation_score.json` contains MIDI pitches, beat positions
and durations, chord voicings, per-bar phrase/section choices, riff patterns,
turnarounds, fills and arrangement gains. `tools/audio/compose_foundation.py`
renders this score with NumPy. It models plucked strings with damped/dispersive
harmonic modes, pick-position coloration and short excitation transients.
Distorted guitars pass through two smooth amplifier stages at64 kHz and an
original cabinet band-pass/resonance response before decimation to32 kHz.
Rhythm takes use separate detuning, pick variation, strumming and stereo pans.
Lead thirds follow natural/harmonic-minor scale choices; short tempo echoes
remain aligned with the score. Bass and kick/snare/hat/ride/crash/tom voices are
synthesized locally. Fixed offline noise excites written notes; it never chooses
the composition and the game never runs this generator.

The five unchanged stem IDs are `title`, `workshop`, `run_base`, `run_pressure`
and `run_boss`. Each WAV is stereo PCM16 at32 kHz with exactly1,428,837 frames:
44.65115625 seconds,128 beats,32 bars. All import settings preserve native PCM,
stereo and sample rate, disable normalization/trimming/compression, and use loop
frames0 through1,428,837. Instrument releases and echoes wrap into the start;
a two-millisecond raised-cosine join makes first/last samples identical.
Per-channel mean removal eliminates residual DC while preserving that join.

Regenerate using a Python with NumPy:

```powershell
python tools/audio/compose_foundation.py
python tools/audio/compose_foundation.py --verify-only
python tools/audio/compose_foundation.py --verify-only --review-dir <external-QA-audio-folder> --review-stem 002c6_metal
```

`--verify-only` rerenders and compares every PCM sample as well as the manifest,
score/generator hashes and native grid. Rendering caches283 voices for5,536
written events. Runtime performs no synthesis. Review files contain24-second
title/workshop/normal/pressure/boss stages and a two-cycle full-boss loop review,
using the default Music trim/slider before Master. Review destinations must be
external and existing review files are refused. Detailed evidence belongs under
`GyroBrothers-QA/002C.6/`; the exact earlier c186 music is preserved externally
in `audio/002c6_metal_original_c186` with its original source/metadata/imports.

## Synchronized runtime and actual Run progression

`scripts/music.gd` retains one `AudioStreamPlayer` and one
`AudioStreamSynchronized` with five fixed substreams. All start at the same
sample. Context changes, intensity, pause, volume and mute change gains; they
never replace, seek or restart the musical transport. Native playback defaults
off; Main explicitly opts in for ordinary play or a scoped audio review.
Headless, packaged inspection and smoke boot stay quiet.

The public interface is `configure_playback(enabled)`, `set_context(context)`,
`observe_run(run_state, player_stats={})`, `set_paused(paused)`,
`apply_settings(settings)`, `notify_cue(kind)` and `music_snapshot()`. Contexts
are title/workshop/run/result/silent. Main passes existing Run census, tier,
calm, survival time and clears plus actual HUD RPM, Redline and invested power
ranks. This controller has no combat host, save access or gameplay callback.

Retained arrangement stages use actual Run survival seconds, Director tiers or
threat clears. Current thresholds/floors are:

| Stage | Seconds / tier / clears (any) | Pressure / anthem floor |
| --- | --- | --- |
| Opening | 0 / 0 / 0 | 0 / 0 |
| Drive | 35 / 1 / 2 | .25 / 0 |
| Lead | 100 / 2 / 4 | .50 / .25 |
| Anthem | 210 / 3 / 7 | .75 / .50 |
| Full | 360 / 4 / 10 | .75 / .75 |

Within one Run, maturity stays earned while temporary pressure can rise/release.
Absolute live/reserved pressure, elite/boss warnings, dangerous RPM, overclock
and build investment can raise the arrangement above that floor. Director census
includes genuinely scheduled pending entries, so an incoming boss can build
music through its real warning. The opening one-rival Run stays at its baseline.
Quantized plateaus, deadband and holds avoid rapid mix thrashing. Temporary
calm density releases after2.5 seconds of evidence; envelope attack/release
times are1.2/2.4 seconds. Actual boss, dangerous RPM and paid overclock can lift
pressure one quarter-step above the current floor, capped at1. Dangerous RPM
also lifts the anthem by a quarter-step; a boss can bring that layer to1.
New context/Run seed or an explicit empty Run reset clears maturity and gain
targets without restarting transport. Pause/drafts duck the Run to35%; paused
observations neither mature nor boost it. Musical chronology and envelopes
continue.

## Mix and bounds

Music routes through its own Music bus to Master. Baseline trim is-8 dB and the
default Music slider is55%; Main/Sound own Master, SFX and mute preferences.
After PCM quantization, the maximum full-boss peak is0.680013(-3.35 dBFS).
All seven0/1 Run gain combinations are bounded before mastering, which also
bounds every continuous0..1 combination. There are zero clipped samples and
zero first/last sample discontinuities. Normal/pressure/full-boss source RMS
are-25.16/-19.96/-18.39 dBFS; title/workshop are-19.78/-27.67 dBFS. These are
full source arrangements, not a claim about every adaptive playback instant.

The existing4 dB major-cue duck and12 dB/0.30-second low-RPM warning window keep
critical collision cues audible. This arrangement changes no SFX sample,
priority, cooldown, pitch, gain or gameplay state. Cost remains five cached
PCM stems(28,576,740 audio bytes), one player, five gain updates and at most64
diagnostic events. The offline generator's larger voice palette adds no native
runtime synthesis cost.

## Verification and review limits

Candidatev3 passed exact regeneration and independent actual-PCM review: all
five stems match the new grid, with zero clipped samples, DC at quantization
noise level(max1.3e-8), and at most0.0039% energy above12.8 kHz. The guitar/lead

measurements establish technical integrity; they do not establish guitar
realism, musical enjoyment or fatigue without human hearing.

`tests/test_music.gd` verifies imported PCM grids, actual native synchronized
mixing against uninterrupted reference cursors across the loop, playback
gating, mix policy and exact seeded combat/RPM/Director/RNG parity.

and new-Run boundaries. `tests/test_music_native.gd` requires explicit native
audio permission and records production Music/SFX buses through controlled
context/cue fixtures. Controlled audition movies remain labelled QA fixtures;
actual Run footage must separately carry real Run observations and recorded
non-silent audio. Godot import must finish before either review path so cached
PCM cannot silently retain the previous grid.
