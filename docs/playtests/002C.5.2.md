# Task 002C.5.2 parts review

Task 002C.5 remains **PENDING HOME HUMAN PLAYTEST**. This stacked checkpoint
expands permanent component content; it does not accept the provisional powers
or Run balance. Neither task is merged to main.

The ordinary latest executable continues the player's existing collection.
A new ordinary save still grants only the chosen Breaker, Bastion or Vane and
its three components. New catalogue cards show **NOT OWNED** until acquired.

For full component review, run
`tools/playtest/windows/QA-parts-catalogue.cmd` from the repository. It opens
the validated latest executable with an isolated collection at
`GyroBrothers-QA/002C.5.2/temp/human_parts_collection.json`. All catalogue parts
are granted through the normal ownership API inside that QA file. Equipping,
preferences and Run diagnostics stay beside that file; the player profile is
separate. This QA collection can retain review assemblies between sessions.

For a separate review collection, set `TOPGAME_QA_ROOT` to the external QA root
and launch the executable with:

```text
-- --qa-catalogue --collection-path="<absolute QA root>/002C.5.2/temp/<review>.json"
```

Catalogue QA refuses missing paths, `user://`, `res://`, the normal player save,
and paths outside the designated task's `temp` folder. A damaged QA collection
is preserved; use a new QA filename instead of resetting the player profile.

In the Workshop, use Left / Right on the keyboard or controller to browse each
component strip. Up / Down changes strip or reaches the launch controls. Mouse
users can click the small `<` / `>` arrows. Focus scrolls the whole selected card
into view. The inspector gives name, component type, rarity, ownership and the
part's physical trade-off. Confirm equips an owned part. **LAUNCH OWNED TOP**
opens the ordinary power draft and continuous Run; **QUICK DUEL / PRACTICE** uses
the currently equipped QA assembly for a real duel.
