All source documents contain an embedded named palette and a

with normal blending, no external linked dependencies or smooth VFX.
The small hostile top has no Blade/Ratchet/Bit build. Ghosts omit its
cap, bit, shadow, and owner marker, preserving the real top's dominance.

NORMAL EDIT/EXPORT WORKFLOW
1. Edit the appropriate .aseprite source in Aseprite.
2. Keep canvas, tag IDs, palette, and contact_pivot slice conventions.
3. Run: python tools/build_power_art.py
   This reads the edited source and exports PNGs + manifest, preserving
   per-frame duration, named tags/layers, and pivots.
4. Import in Godot and inspect movement at native640x360 and integer
   scales. Texture filtering stays nearest; mipmaps remain disabled.

The small source exporter supports RGBA normal image layers, layer/cel
opacity, raw/compressed/linked cels, named tags and pivot slices. It
rejects unsupported blend modes or groups rather than silently losing
artist work. For those features use Aseprite's own batch export with
rows/8 columns for effects and small tops,6 columns for icons, preserving
the metadata conventions in assets/powers/manifest.json.

python tools/build_power_art.py --author intentionally reconstructs and
OVERWRITES these three sources from the initial deliberate cluster
definitions. Do not use --author after making manual source edits.

AUDIO
python tools/build_power_audio.py rebuilds9 short, dry, original mono
PCM16 mechanical cues using deterministic offline synthesis. Runtime
mixing has8 channels with priority replacement; ordinary small contacts,
Afterimage and Chain cues are rate-limited. Recovery/acquisition outrank
crowd contacts. Audio randomness is independent of gameplay randomness.

QA
godot --headless --path . --script res://tests/test_presentation.gd
checks named atlas bounds/timing, native canvases, finite audio, same-
frame crowd aggregation and the8-channel priority cap.

Optional non-headless --capture-dir=<absolute directory> records a
seeded all-power swarm motion sequence and a separately held12-body
stress fixture. It reports simulation CPU, draw-command submission CPU,
and frame wall time. This fixture is not human playtest evidence and
does not measure asynchronous GPU time or WebGL performance.
