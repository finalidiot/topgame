# Task 002C — human build checkpoint

Run `SpinningMetal-002C.exe` in the delivered Windows package for the ordinary
eight-encounter Run. The same build is kept in the repository at
`releases/windows/SpinningMetal.exe`.
Choose Breaker, Bastion or Vane, collect a first power, and use earned choices
to add powers or reinvest. Redline, Dead Centre and Afterimage each have
Rank I, Rank II and one chosen mutation. Mutations and specific powers are
not guaranteed in ordinary play.

Steer with WASD/arrows or the left stick. Space/bottom face button bursts.
Shift/shoulder/trigger brakes. Esc/Menu pauses. Release Confirm, steering
and brake after choices. Left/right chooses between mutation branches.
Press F2 during combat to hide or restore the HUD; pausing restores it.

For a direct comparison, the delivered Windows folder contains seven
`Practice-*.bat` launchers. They start an isolated encounter with seven
equipped powers: one defining mutation and six Rank I supports. Hybrid
instead combines Runaway, Counterweight and Slipstream. These are setup
fixtures for human testing, not earned runs or pacing evidence. Combat uses
normal physics and AI; no kills, damage, reserve refills or procs are injected.
Practice uses the authored starter that naturally suits the path, but normal
Runs allow every power on every starter. Restart Duel/Rematch repeats the preset.

| Build | Try this |
| --- | --- |
| Runaway | Burst toward a rival, then keep landing meaningful hits before overload expires. Miss a follow-up to feel the engine fall out of the state. |
| Breakneck | Line up an angle before Burst. Commit to the charge, then brake and recover its wobble. Compare with sustained Runaway attacks. |
| Bulwark | Brake near the arena centre and wait for full grounding. Let the rival hit you. Then steer hard or Burst to feel the lock break. |
| Counterweight | Anchor under brake, absorb hits, watch the visible storage grow, aim and Burst to release the captured force. |
| Ghost Circuit | Move fast around a broad loop. Keep the route live, close within roughly one top width of the starting path, and watch the enclosure energise. Avoid tiny turns that bleed all speed. |
| Slipstream | Draw an extended route, then cross an older active segment or re-enter it. Compare speed, handling and trail language with Ghost Circuit. |
| Hybrid | Hold centre to store force, Burst out into Runaway, and reuse routes to recover movement. Judge whether supports make a readable machine. |

The mutation screen and acquisition event should also be tested through a
normal earned Run; practice starts with the branch already equipped.

For Runaway, Bulwark and Ghost Circuit, hide the HUD and watch five seconds.
Check whether the movement and combat presentation alone identify the build.
The automated captures are supporting evidence, not a substitute for this judgment.

Record starter, chosen powers/ranks, mutation, keyboard/controller model,
time and encounter, then answer:

1. Does Redline become genuinely extreme?
2. Does Bulwark make defence feel exciting rather than passive?
3. Is Counterweight's defence → storage → offence loop understandable?
4. Does Afterimage make movement itself feel like a build?
5. Does a mutation feel like a major event?
6. Can you tell what changed immediately after an upgrade?
7. Do several powers feel like an interacting machine rather than visual noise?
8. Are six/seven powers moving toward the desired absurd late-run fantasy?
9. Do you already think, “I want to see what happens if I combine X with Y”?

No human feel or physical-controller acceptance is claimed for this build.
