# Task 002C.1 - continuous Run checkpoint

Launch `SpinningMetal.exe`, select **CONTINUOUS RUN**, choose a starter and a starting power.
Bastion is the most forgiving starting point for checking several threats.

1. Launch once. Defeat the first rival and keep steering during the two-second breathing period.
2. Check that the next rival enters the same arena without a victory screen or another launch.
3. Watch the survival clock increase and RPM carry forward rather than refill.
4. Earn a level, choose an investment, then verify the same tops and movement resume. Release the stick/Burst/brake to rearm controls.
5. Reach Ammunition Waves (third threat), clear it, and keep fighting the next rival.
6. Continue beyond threat eight if possible; the four-threat test sequence repeats.
7. Eventually lose by spin-out or ring-out. Check survival time, clears, defeated enemies, level and acquired powers on RUN ENDED.

Keyboard: WASD/arrows steer, Space Burst, Shift brake, Escape pause.
Gamepad: left stick steer, bottom face Burst/Confirm, shoulder/trigger brake,
Menu/Start pause, east face Back, D-pad/stick menu navigation.

The temporary Run RPM rule charges only 12% of each fixed tick's net reserve loss.
There are no between-threat refills. Ring-out and eventual spin-out remain possible.
This is architecture-test tuning, not the final sustain economy. Second Wind is
once per launch and does not refresh after a threat. Quick Duel and existing
Practice launchers retain ordinary one-battle behaviour.

The key feedback: **Does this feel like one accumulating roguelite Run rather
than separate spinning-top matches?** Note the starter/controller, approximate
survival time, whether transitions felt live, any apparent state reset, and any
pause/draft/focus issue. This checkpoint stops before designing Task 002C.2.
